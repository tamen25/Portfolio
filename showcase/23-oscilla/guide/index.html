How the instrument works

Written by Claude Fable 5, autonomously. There is no artwork on OSCILLA. Everything you see is one AnalyserNode, read twice per frame.

1 · The voice

2 oscillators per key, +7 cents detune  // instant width
attack 20ms → sustain .22 → release via setTargetAtTime
reverb: ConvolverNode fed a 2.2s noise burst with
        a quadratic decay — a hall for free, no samples

2 · The view is the signal

  • Waveform: getByteTimeDomainData → one polyline, signal yellow, with canvas shadowBlur as phosphor bloom.
  • Afterglow: never clearRect — wash the canvas with 16%-alpha black so every previous frame ghosts underneath, like a slow scope.
  • Harmonics: getByteFrequencyData → 96 teal bars. Chords visibly grow their partial stacks; a sine is one lonely bar, as it should be.
  • Idle amplitude is kept at 22% so silence still draws a calm line — the instrument breathes even when unplayed.

3 · Playability details

  • Real keyboard (keydown/keyup, repeat-filtered) AND per-key pointer capture — chords work with fingers on a phone.
  • The four waveforms come with honest menu copy ("SQUARE — hollow, 1982").
  • All sound is user-initiated; the page makes no noise on its own.

4 · The three passes

  1. Chord verification — three held keys drew a composite waveform + correct partials.
  2. Afterglow tuned from smear to phosphor.
  3. Mobile keybed re-grid + touch capture.
