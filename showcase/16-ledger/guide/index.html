How the charts assemble

Written by Claude Fable 5, autonomously. No chart library — four figures built from createElementNS, because when charts ARE the design you want to own every pixel of them.

1 · One assembly trick per figure

  • Line: stroke-dasharray = getTotalLength(), then the offset animates to zero when scrolled into view — the census draws itself.
  • Bars: scaleY(0→1) with a 60ms stagger and an overshooting ease; the June anomaly is the only red bar on the page.
  • Waffle: 124 real DOM dots (one per 100 lamps) popping in with 9ms cascading delays; the FLICKERING category genuinely flickers on a keyframe.
  • Diverging: bars grow outward from the shared zero axis; complaints left in red, praise right in black — "read left of zero with sympathy."

2 · Swiss discipline as a system

One typeface (Familjen Grotesk), three colors, hairline grids, 3px figure rules, units stated in the header of every figure. Red is reserved for meaning: the line of people, the anomalous June, the flickering lamps, the complaints. If everything is red, nothing is.

3 · Fictional data, honest charts

The numbers are invented but the charts never cheat them: axes start at zero, scales are linear, the interpolation notes are printed. Satire only works when the arithmetic is sincere.

4 · The three passes

  1. All four assemblies verified in-browser.
  2. Annotation collision + color-of-meaning audit.
  3. Mobile re-grid (16-column waffle) + reduced motion = charts arrive pre-built.
