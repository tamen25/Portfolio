How the folios were pressed

Written by Claude Fable 5, autonomously. The design bet: treat generated images the way an archivist treats specimens — as objects to be mounted, taped, tissued and catalogued, not as decoration.

1 · Generating specimens, not pictures

  • Four prompts to Higgsfield soul_2, one species each, all sharing the same vocabulary: cream archival paper, aged tape strips, top-down flatbed scan lighting. Shared vocabulary is what makes four generations feel like one drawer.
  • Despite explicit "no text, no labels, no handwriting", all four came back with gibberish annotations — herbarium sheets in training data are covered in writing, and that prior wins. The fix is an edit pass, not a re-roll: nano_banana_pro removed every mark while keeping plants, tape and stains identical. Zoom into everything you generate.

2 · The folio interaction

  • Each specimen lives behind a cover styled as a filing folder. Opening rotates the sheet down from rotateX(-64deg) with a slightly overshooting ease — paper has spring.
  • The photograph is covered by a tissue layer (translucent gradient + 1.5px blur) that lifts by itself 1.1s after opening — the archivist's gesture, automated. Hover puts it back to lift again.
  • One folio open at a time. An archive is not a tab bar, but it behaves like one: aria-expanded, keyboard focus, and a plus-tie that rotates into a minus.

3 · The writing is the second design system

Every specimen carries a collector's note that does narrative work — the fern's forest is a parking structure now; the eucalyptus arrived by post in 1962. The catalogue admits its losses ("eaten by time (beetles)"). Archives are moving because they are incomplete; the copy honors that.

4 · The three passes

  1. Interaction pass — open/close, accordion, unfold, tissue lift.
  2. Asset hygiene pass — found gibberish on all four scans, ran four edit passes, re-verified at full size.
  3. Mobile pass — folios restack, tissue lifts on touch, reduced motion opens instantly.

5 · Replicate it

  • One prompt vocabulary per collection — cohesion beats quality per image.
  • Give every image a physical costume (tape, tissue, shadow) so it stops reading as "AI image".
  • Deploy: netlify deploy --prod --dir .
