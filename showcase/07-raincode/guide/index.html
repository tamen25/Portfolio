HOW THE WINDOW WORKS

Written by Claude Fable 5, autonomously. RAINCODE is a sandwich of four layers: a generated film, procedural rain, wipeable fog, and one neon title. The interaction budget went to a single verb: wipe.

1 · The film (generated)

  • City plate from Higgsfield soul_2: "view from inside a high-floor window… neon teal and magenta… no text, no people." The model composed real window mullions into the shot — pass 1 deleted my fake CSS mullion instead of fighting it.
  • The plate went to kling3_0_turbo as a start frame with a cinemagraph prompt (flicker, drifting lights, moving haze, no camera). 5 seconds, loops, 3.5MB, poster fallback for reduced motion.

2 · Rain that isn't a gif

Ninety streaks on a canvas. Each is a vertical gradient line with a bright bead at the tip, random length/speed/drift, recycled at the bottom. Drawing rain as streaks-on-glass instead of falling drops is what sells the window.

3 · Fog you can wipe

// the whole trick
fx.globalCompositeOperation = 'destination-out';
radialGradient(cursor, 0 → 62px);   // soft eraser
fx.fill();                           // glass clears
setInterval(paintFog(.045), 300);    // …and re-condenses

The fog layer is a grey gradient + 240 condensation specks. The cursor erases with a feathered radial brush; a timer paints 4.5% opacity fog back every 300ms, so the city always fades away again. touch-action:none makes fingers work like cursors.

4 · The three passes

  1. Caught the double-mullion conflict between generated plate and CSS frame.
  2. Verified the wipe by dispatching synthetic PointerEvents along a Lissajous path — fog cleared, film visible, hint label faded.
  3. Mobile touch wiping, reduced-motion (film paused on poster, rain frozen, recondensation stopped — one clean wipe still works).

5 · Replicate it

  • Generate the world once; spend your code on the glass between it and the visitor.
  • destination-out + soft radial brush = every "scratch-off" interaction you've ever liked.
  • Budget: one image + one 5s video ≈ 8 credits. Deploy: netlify deploy --prod --dir .
