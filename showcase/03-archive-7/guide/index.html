HOW THIS FILE WAS FORGED

Written by Claude Fable 5, which designed, wrote and built ARCHIVE-7 autonomously. This site ships zero images — every texture, stamp and diagram is CSS or inline SVG.

1 · PAPER WITHOUT PHOTOGRAPHS

  • Grain: one inline SVG feTurbulence data-URI, tiled as background-image over the desk, sheets and stamps.
  • Age: warm inset box-shadows (rgba(140,110,50,.12)) pool "sun yellowing" toward sheet edges; each sheet carries ±0.5° rotation so the stack feels handled.
  • Stamps: double borders + mix-blend-mode:multiply + rotation. Lesson from pass 1: a noise mask with 5% alpha erased them entirely — blend, don't mask.

2 · THE REDACTION GAME

  1. Every secret is a real <button> with transparent text on an ink background — screen readers announce "redacted text, activate to declassify".
  2. Rough bar shape: an eight-value border-radius (3px 40% 4px 38% / 50% 4px 44% 3px) plus a tiny skew — no two bars look alike.
  3. The counter reads document.querySelectorAll('.redact').length — copy can grow without breaking the "22 / 22".
  4. Revealing everything unlocks the twist: the file's last redaction is the reason the Registry closed the case. Give the completionist a narrative payoff, not a badge.

3 · DOCUMENT CHOREOGRAPHY

  • The folder cover rotates open with a single CSS 3D transform (rotateX(-96deg), perspective on the parent).
  • Rubber stamps "slam" via IntersectionObserver — scale 2.6→1 with an overshoot ease.
  • The surveillance route draws itself with the stroke-dashoffset trick when scrolled into view.
  • Reduced motion: no slams, no drawing, folder opens instantly — the file still reads perfectly.

4 · THE THREE PASSES

  • Pass 1: invisible stamps (mask alpha bug) — fixed by removing the mask.
  • Pass 2: scripted a full playthrough (22 clicks) — verified counter, completion banner, stamp slam and map drawing.
  • Pass 3: mobile revealed the documents were visible before the folder opened — author display:flex beats the hidden attribute; fixed with an explicit [hidden]{display:none} rule.

5 · REPLICATE IT

  • Pick a physical artifact and imitate its flaws: rotation, stains, overlap.
  • Make decoration honest: the counter counts, the route is a real path, the twist is text.
  • One HTML + one CSS + 60 lines of JS. Deploy: netlify deploy --prod --dir .
