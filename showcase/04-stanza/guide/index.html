How Invisible Forces was set in motion

Written by Claude Fable 5, which wrote the poem, designed the type system and built the site autonomously. The premise: motion is not decoration here — the motion is the meaning. If an animation didn't enact its stanza's verb, it was cut.

1 · One behavior per stanza

  • GRAVITY — chars drop from random heights with bounce.out; random stagger so the line lands like dropped cutlery.
  • WIND — chars gust in from the left, then loop tiny random drifts forever: wind never finishes editing.
  • TIDE — a sine wave staggered through the line (yoyo repeat), first verse flows out, the answer flows back.
  • FOG — each char loops its own opacity/blur cycle at a random phase; legibility itself is the animation.
  • HEAT — chars rise with scaleY stretch from the baseline, then shimmer with fast skew jitter.
  • ECHO — the closing line exists three more times, blurred and fading, drifting away on slow loops.
  • STILLNESS — everything converges from random scatter with expo.out and then nothing moves. Restraint as payoff.

2 · The page is weather too

Each stanza carries a data-theme; an IntersectionObserver stamps it on <body> and CSS custom properties crossfade the entire page — graphite for gravity, sea-glass for tide, ember for heat, lavender dusk for echo, pure white for stillness. Two rules, seven moods.

3 · A splitter with typographic manners

Pass 2 caught the classic kinetic-type bug: naive per-char spans let lines break mid-word ("sho / re"). The fix is structural:

text.split(/(\s+)/) → word spans {display:inline-block; white-space:nowrap}
                       → char spans inside each word

Words wrap; letters never separate. Screen readers get the original line via aria-label while the spans are hidden from them.

4 · Fraunces earns its axes

The variable axes do real work: display sizes run opsz 144; the italic cover word runs WONK 1 (Fraunces' intentionally crooked alternates) and SOFT 60. A typeface with opinions, given room to have them.

5 · The three passes

  1. Verified all seven behaviors with scrolled screenshots — the only honest way to QA motion.
  2. Fixed the mid-word wrapping (structure, not patch).
  3. Mobile: hid the spine numerals that collided with verses at 390px; confirmed the reduced-motion poem reads perfectly with zero animation.

6 · Replicate it

  • Write the words first. Every animation must be justified by a verb in the text.
  • Loop what shouldn't finish (wind, fog, echo); play-once what should (gravity, stillness).
  • Zero images, zero build, ~200 lines of JS. Deploy: netlify deploy --prod --dir .
